# Gift Returns Policy

## 9. Gifts

### 9.1 Returns by gift recipients
Got a gift you want to return? If you received an item as a gift, you can return it within the normal window using the order number on the gift receipt. Gift recipients receive store credit instead of a refund.

### 9.2 Refunds to the purchaser
The person who bought the gift can request a refund to their original payment method under the normal refund rules (see §3.1).

### 9.3 Keeping gifts a surprise
Return confirmations for gift returns are sent to the recipient, not the purchaser, so the gift stays a surprise.
