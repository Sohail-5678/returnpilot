# Exchanges Policy

## 4. Exchanges

### 4.1 Size and color exchanges
You can exchange an item for a different size or color within your return window (see §2.1 and §2.2). Exchanges are free for US orders.

### 4.2 Exchanges for final-sale items
Final-sale items can't be returned or refunded, but if a final-sale item arrives damaged we will exchange it for the same item (see §6.2).

### 4.3 How exchanges are processed
Exchanges are handled by our support team. ReturnPilot opens a support ticket with the item and the size or color you want, and the team confirms availability by email.
