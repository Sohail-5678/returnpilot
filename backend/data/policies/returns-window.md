# Returns Policy

Northwind Outfitters is a demo store. These policies are fictional and used only by the ReturnPilot demo.

## 1. Starting a return

### 1.1 How to start a return
Start a return from your order page or by asking ReturnPilot in chat. Tell us which item you want to return and its condition (unopened, opened, damaged, or wrong item). We email a return label once the return is created.

### 1.2 Condition of returned items
Items should be unworn, unwashed and in their original packaging with tags attached. Items that arrive damaged or are the wrong item are always accepted within the damaged-item window (see §5.1).

### 1.3 Return methods
You can drop a return off at any Northwind Outfitters store or partner drop-off point, or ship it back with the label we send. Store drop-off is free for US orders.

## 2. Return windows

### 2.1 Standard window
How many days do you have to return something? You can return most items within 30 days of delivery. This applies to Standard and Silver members.

### 2.2 Gold member window
Gold loyalty members get an extended 60-day return window from the delivery date.

### 2.3 How days are counted
The window starts on the delivery date shown on your order. Orders that are still processing or in transit can't be returned until they are delivered. Cancelled orders are never charged, so there is nothing to refund.
